# Magma India activities have moved to TOSSI Foundation

Magma India is no longer the active home for new development, releases, coordination, or community activity.

All future telecom open-source system integration work is now continued under:

## 👉 [TOSSI Foundation](https://github.com/TOSSI-Foundation)

Website: [tossi.org](https://tossi.org)

This GitHub organization remains available for historical reference, continuity of public links, and access to previous work.

For all new activity, please follow the TOSSI Foundation GitHub organization.
